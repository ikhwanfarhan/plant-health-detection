About the System

The Web-Based Plant Health Detection System Using Machine Learning is developed to help users analyse the health condition of plant leaves through image classification.

Users can upload a plant leaf image and the system uses a YOLOv8 machine learning model to analyse the image. The system provides the plant name, health status, disease name and confidence score.

How It Works

Detect plant health in four simple steps

Step 01

Upload Image

Upload a clear image of a plant leaf to the system.

Step 02

AI Analysis

The YOLOv8 model analyses the uploaded image using learned visual patterns.

Step 03

Detect Plant Health

The system identifies the plant, health status and disease.

Step 04

View & Print Result

View the plant name, health status, disease and confidence score, then print the detection result.

System Features

  • Plant leaf image upload and classification
  • Healthy or unhealthy plant health status
  • Disease identification for unhealthy plants
  • Confidence score display
  • View and print previous detection reports
  • Search detection records
  • Administrator plant information management
